# TaskPulse

A small To-Do List web app built during placement training while experimenting with **Antigravity** and AI-assisted development.

### What it includes

* Task creation, editing, completion and deletion
* Priority and category management
* Search and filtering
* Progress tracking
* Light / dark mode
* Local browser storage
